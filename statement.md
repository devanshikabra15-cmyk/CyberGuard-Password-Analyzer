# Project Statement

## Project Title
CyberGuard Password Analyzer

## Problem Statement
Users often create passwords without knowing whether the password contains basic characteristics associated with stronger password composition. A simple command-line tool can provide immediate feedback about password length, character variety, common-password usage, estimated entropy, and improvement suggestions.

## Scope
CyberGuard focuses on local, command-line password analysis. It evaluates a password entered by the user and produces a security-oriented report. It does not send passwords to an external service or claim to guarantee resistance to attacks.

## Target Users
- Students learning Python
- Users who want basic password-composition feedback
- Demonstrators/evaluators reviewing a Python command-line project

## High-Level Features
1. Password composition analysis
2. Password score and strength classification
3. Security-level classification
4. Entropy estimation
5. Common-password detection
6. Security recommendations
7. Command-line report
8. Input validation
9. Automated tests
